# Changelog

## 1.4.0

- GLPI imports support up to 100,000 computers, progress reporting and adaptive
  response-page reduction. Failed imports preserve the previous DNS snapshot.
- Add Zabbix source
- CLI host search with Ansible group metadata.
- First-launch installation of the terminal command, Settings status/retry and
  exact-link cleanup during uninstall. Shell startup files are unchanged.
- Universal macOS 13+ app and DMG: Developer ID signed, Apple-notarized and stapled.
