# Changelog

## 0.8.0

Prepared for the first public distribution of InvDNS for macOS.

- Local static Ansible YAML/INI inventory files and recursive folders.
- Local IPv4 DNS, configurable suffix/TTL and persistent cache.
- Native menu bar resolver control and Sources, Conflicts and Settings windows.
- Native privileged resolver management and editable resolver settings.
- GUI-controlled daemon lifecycle and launch at login.
- Safe Quit closes all InvDNS windows after confirmed cleanup, including when
  Settings, Sources or Conflicts is open.
- Foreground activation for Sources, Conflicts and Settings.
- In-app uninstall with confirmation and InvDNS data cleanup.
- Universal Developer ID signed and notarized app/DMG for macOS 13 or later.

The public version is `0.8.0`.
